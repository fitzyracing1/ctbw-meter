# CBWT meter

> **Status:** Idea + one manual analysis. Eight repos were scored once by reading code (only bound-loop from a real run). No meter code yet.

A tool that scores a repo on four costs kept as low as possible: Cost (money/compute), Bridge (glue to the real world), Work (steps, retries, loops), Theory (unverified guesses). Each is a bit; 0000 is best, 1111 is fully dark. The concept lives in fitzyracing1/ai-tenets.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Lex bot, Oct 26 2026) and was not taken further at the time. This repo records it so it can be picked up later.
